# 待辦單：自訂產業鏈「拆段引導」

狀態：Backlog（2026-10-03 開單）｜來源：階段六 PR #1 驗收時的待決 D｜排程：**10/23 期別案上線之後**

## Problem
學員自訂產業鏈時很可能不知道怎麼拆段。段的定義是「同一個瓶頸位置上的同業」，不是上中下游產業分類；只拆一段就沒有橫向比較，L1 到交集全部失去意義。目前編輯器新增鏈後只給一個空的「子段 1」，沒有任何引導。

## 決策紀錄
2026-10-03 Jason 拍板：階段六先合併，本單另開，不阻擋合併。

## 暫行做法（不寫程式）
月例會要跑的產業由**講師先拆好、下發**，學員套用後微調。功能已存在（分段設定下發），屬課堂流程安排。

## 候選方案（待第二期實際使用後再決定做不做）
1. **拆段前置指令**：讓學員問一般 AI「這條鏈依瓶頸位置可拆成哪幾段、每段台股代號與名稱、每段租金來源」，輸出成控制台可一鍵匯入的 v2 格式。順帶解掉手打代號的麻煩。⚠ 非教材內容，需顧老師過目。
2. **編輯器內提示**：子段區上方寫拆段判準＋一個航運示範（貨櫃／散裝／港埠，租金來源各異）；只有一個子段時顯示琥珀警告「一段沒有橫向比較可做，至少拆兩段」。
估計：1＋2 約半天工。

**不做**：內建航運、金融等預設模板——等於替老師拆段，違反「先驗是老師的判斷」。

## 決定做之前要先觀察的
第二期學員實際使用自訂鏈時：有多少人只拆一段？講師下發是否已足夠？卡點是「不會拆」還是「懶得手打代號」？後者只需方案 1 的匯入半邊。
