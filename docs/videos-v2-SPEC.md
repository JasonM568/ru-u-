# 課程影片 v2：逐支開通 × 課程式播放介面

狀態：PRD v1.0（2026-10-03 定稿）｜決策者：Jason｜**上線目標：2026-10-17 前**（趕在 10/23 二期進名冊之前）
前置：Cohort v1 已於 2026-10-03 上線（`cohort-v1-SPEC.md`），本案直接建立在其期別機制之上。

## Goal / Problem

1. **開通權限只到「期別」**：Cohort v1 讓二期看不到一期影片，但同一期內，影片一上傳全期立刻看得到。管理員無法「先上傳、檢查無誤再開放」，也無法給個別學員補課。
2. **動線不像課程平台**：`/videos` 是一區塊一區塊的卡片牆，看不出課程脈絡，看完一支要滑回去找下一支。

目標：影片改為「上傳是草稿 → 管理員開通給指定對象 → 學員在課程式播放頁依序觀看」。

## Users & Scenarios

- **管理員（講師）**：上課後貼錄影連結 → 草稿狀態下自己先播一次確認 → 按「開通」選對象（期別／個人）→ 學員即可觀看。補課、旁聽者可單獨開通。
- **學員**：登入 → `/videos` 課程目錄 → 點某一堂 → 播放頁觀看，側欄看得到整門課結構，可跳集或按「下一集」。

## MVP Scope

**A. 上傳即草稿、開通時選對象（2026-10-03 拍板）**
- 新增影片只填標題、網址、分類、說明 → 狀態為**草稿**，只有講師看得到。
- **移除 Cohort v1 在影片上傳表單加的「目標期別」選單**——對象一律在「開通」時決定，一個地方管到底。（教材與分段設定的目標期別選單不受影響，維持原樣。）
- 「開通」對話框選擇可看對象，可組合：
  - **期別：可複選**（例：一期＋二期，不含未來的三期）
  - **所有期別**（含未來新期別）
  - **指定個人**：補課、旁聽等特例，可與期別並存
- 已開通的影片可隨時修改對象或「取消開通」退回草稿，即時生效。
- **開通快捷**：
  - 「沿用上一支影片的對象」
  - 「套用到同分類的所有影片」（覆寫型，需二次確認，明列會影響哪幾支）
  - 指定個人時可「整批選取某期別／某隊伍的成員」→ 展開為個人名單（快照，之後隊伍變動不自動跟著改）

**B. 既有影片（2026-10-03 拍板）**
- 正式站現有 10 支影片**自動視為「已開通給 2026 第 1 期」**，一期學員完全無感。

**C. 課程式播放介面**
- `/videos`：課程目錄，依四分類（課前資料／Day 1／Day 2／補充教材）分章，每章列出該使用者有權看的影片；空的章節不顯示。講師另外看得到草稿，並明確標示「草稿」。
- `/videos/[id]`：獨立播放頁＝大播放器（16:9）＋章節側欄＋標題／說明＋上一集・下一集。側欄只列有權看的影片，目前這支高亮。
- 手機（≤420px）：側欄收到播放器下方、可摺疊。
- 上一集／下一集的順序＝分類順序 → 建立時間，且只在「有權看的集合」內計算。
- **影片狀態提示**（2026-10-02 實際踩過）：
  - 轉檔中 → 「影片處理中，請稍後再試」
  - 來源為 YouTube「私人」→ 學員端「影片尚未開放」；講師端「這支在 YouTube 是私人影片，請改成『不公開』才能播放」
- **新增時防呆**：送出前以 YouTube oEmbed 檢查，私人影片（403）直接擋下並提示改設定。

## Out of Scope

觀看進度／完課率／繼續觀看、留言問答、字幕上傳、倍速（播放器原生已有）、DRM 與防側錄、觀看紀錄報表、拖拉排序（先用建立時間）、可自訂章節分類、**Vimeo 網域鎖定（已拍板列下期）**。

## User Stories

1. 身為管理員，我貼上影片後它是草稿，我自己先看過、按開通才讓學員看到。
2. 身為管理員，我開通時可以勾選一期、二期或兩期都開，也能單獨開給補課的學員。
3. 身為管理員，我能沿用上一支的對象，或把同一組對象套用到整個 Day 1。
4. 身為學員，我在一頁看到整門課的結構，看完一堂直接按「下一集」。
5. 身為學員，我在任何地方都看不到沒開通給我的影片，包括標題。
6. 身為一期學員，改版當下我原本看得到的 10 支影片一支都不少。

## Acceptance Criteria

- **AC1** 開通給 A 不含 B：A 的目錄、側欄看得到且能播；B 的目錄、側欄、API 回應皆無此影片；B 直接輸入 `/videos/<id>` 得 404 或導回目錄（不是空白播放器）。
- **AC2** 權限由 **RLS 保證**：以 B 的身分直查資料庫查不到該列。
- **AC3** 草稿：任何學員（含同期）皆看不到；講師看得到且標示「草稿」。
- **AC4** 複選期別：開給一期＋二期 → 兩期可見；之後新增的三期不可見。開給「所有期別」→ 三期也可見。
- **AC5** 指定個人：開給二期的某學員 X → X 可見，二期其他人不可見，一期不可見。
- **AC6** 取消開通 → 立即退回草稿，學員端消失。
- **AC7** 快捷：「沿用上一支」正確帶入且可再增刪；「套用到同分類」二次確認、只影響該分類，不誤傷其他分類；**只覆寫已開通的影片，草稿完全不受影響**（2026-10-03 審查後拍板，避免未試播的草稿被順手開通）。
- **AC8** 停權學員看不到任何影片（含被指定個人開通者）。
- **AC9** 播放頁：側欄分章、當前集高亮；第一集無上一集、最後一集無下一集；側欄集數與目錄一致且皆已套權限。
- **AC10** 狀態提示（2026-10-03 審查後修訂為 **fail-open**）：播放頁**一律渲染 YouTube iframe**；只有 oEmbed 明確回 401／403（私人）時才以提示取代播放器。播放器下方固定一行「若影片無法播放，可能仍在 YouTube 處理中，請稍後再試」。oEmbed 結果短期快取。新增私人影片網址被擋。
  - 理由：oEmbed 分辨不出「轉檔中」（轉檔中照樣回 200）；且原實作在 YouTube 限流／逾時時會擋掉全站影片。寧可讓 YouTube 播放器自己顯示錯誤，也不能讓學員被擋在能看的影片外。
  - 上線前必驗：以正式站實際影片網址實測播放頁出現 iframe。
- **AC11** 手機版播放器不溢出、側欄可收合。
- **AC12** **一期回歸**：上線後一期 11 位學員可見的影片集合與上線前**完全一致**（10 支）——比照 Cohort v1 的 AC1 做遷移前後逐人快照比對。

## Risks / Open Questions

- 🟠 **與 Cohort v1 欄位的整合**：`course_videos` 目前有 `cohort`（NOT NULL）＋`all_cohorts`，可見性由此判定。改為「開通對象」後，這兩欄的角色要由 Tech Lead 決定（保留為中繼資料、改用對象表、或移除），**前提是可見性只能有一個來源**，不能兩套規則並存。
- 🟠 **一期回歸**：既有 10 支影片的遷移必須保證一期可見集合不變（AC12）。
- 🔵 權限擋不住連結外流（YouTube 未列出）——已知，Vimeo 網域鎖定列下期。
- 🔵 「整批選隊伍」是快照，隊伍之後變動不會自動同步——刻意設計，避免名單默默變動。

## Handoff Notes

**Backend（Tech Lead 先提資料模型再動手）**
1. 候選模型：`course_videos` 加開通狀態（例 `published_at`，null＝草稿）；新增 `elite.video_audiences`（每列為「一個期別」或「一個使用者」，二擇一，`on delete cascade`）；「所有期別」可沿用 `all_cohorts`。請評估並回報選定方案與理由。
2. RLS：`is_instructor() OR (已開通 AND is_enrolled() AND (所有期別 OR 對象含 my_cohort() OR 對象含 auth.uid()))`。**權限必須落在 RLS。**
3. **Cohort v1 審查帶來的硬性約束**：
   - 正式庫 `elite` schema 有 default privileges（`authenticated=arwd`），**每張新表先 revoke 再明確 grant**；本機演練必須重現此 default ACL。
   - 新表**不會自動套上** `cohort_v1_active_gate`，必須自帶停權閘門（比照建立 restrictive gate）。
   - 遷移比照 Cohort v1：交易式、guard 守門、附回滾 SQL；正式庫由 PM 以 MCP `apply_migration` 執行。

**Frontend**
1. `/videos` 目錄、`/videos/[id]` 播放頁、章節側欄、上一集／下一集。
2. 新增影片表單移除目標期別選單；新增「開通」對話框（期別複選＋所有期別＋指定個人＋三個快捷）、「取消開通」。
3. 狀態提示與 oEmbed 防呆。`lib/video.ts` 解析器已驗證正確，不需改動。
4. 破壞性操作（套用到同分類、取消開通）用頁內對話框二次確認。

**QA**
1. 最關鍵：AC1／AC2／AC3／AC5 以合成帳號實測，含直接打網址與直查資料庫兩條路徑。
2. AC12 一期回歸：遷移前後逐人快照比對。
3. 邊界：影片 0 支、只有 1 支、某分類全空、學員有權看的影片為 0 支（顯示空狀態而非報錯）。
4. 回歸：教材、分段設定的目標期別選單不受影響。
