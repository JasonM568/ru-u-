# 五層作業流指令：AI 供應鏈專用段落的通用版草稿（待顧老師簽核）

> 背景：控制台自 2026-09-02 起支援「自訂產業鏈」，學員可以把同一套作業流套到任何台股。
> 八道指令裡只有三段是 AI 供應鏈專用的教材原文，其餘全部通用。
> **簽核前程式不改任何指令字串**，自訂產業鏈在這三站只顯示琥珀色提示「AI 供應鏈專用段落・待講師簽核」。
> 簽核後的實作：保留 AI 原文，在 `lib/flow/prompts.ts` 依 `chainKind` 代入通用版，移除提示（一個小 commit）。

原則：結構、行數、輸出格式一字不動，只把「AI 供應鏈專屬的名詞」換成「本產業鏈」的同位概念。

## A1　L0 環境判讀　第 ③ 項與交棒卡第三行（`prompts.ts` `l0`）

教材原文：
```
③ AI 資本支出週期目前位置：擴張期／消化期／收縮期
　 請列出判斷依據，至少包含：CSP 資本支出指引、
　 實質利率、電力供給限制
…
AI capex 週期：（擴張期／消化期／收縮期）
```

通用版草稿：
```
③ 本產業的需求／資本支出週期目前位置：擴張期／消化期／收縮期
　 請列出判斷依據，至少包含：下游主要客戶的資本支出或採購指引、
　 實質利率、本產業最關鍵的供給限制（產能、原料、法規或電力擇一）
…
產業週期：（擴張期／消化期／收縮期）
```

對應檢核項（`stations.ts` L0 第 3 條）通用版：
「產業週期的判斷依據有列出下游資本支出指引、實質利率、關鍵供給限制」

## A2　L2 前置 財報蒐集　第 ④ 項與 5(b) 的例子（`prompts.ts` `l2Pre`）

教材原文：
```
④ AI 相關營收佔比（只採用公司法說會、年報或重大訊息
　 明確揭露的數字；媒體推估一律不採用，填「未揭露」）
…
　 (b) 哪些公司的 ROIC 因產業特性可能失真
　　　（例如工程業的在建工程、長期合約）
```

通用版草稿：
```
④ 本產業鏈相關營收佔比（只採用公司法說會、年報或重大訊息
　 明確揭露的數字；媒體推估一律不採用，填「未揭露」）
…
　 (b) 哪些公司的 ROIC 因產業特性可能失真
　　　（例如工程業的在建工程與長期合約、金融業的資本結構、
　　　　航運業的船舶折舊）
```

對應注意事項（`stations.ts` L2P 第 2 條）通用版：
「『本產業鏈相關營收佔比』大部分公司可能都是『未揭露』——那個空白本身就是資訊，代表這家公司在這條鏈上的曝險無法查證。」
